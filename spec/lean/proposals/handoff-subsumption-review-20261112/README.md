# Summary relations versus demand queries

This is a bounded review package. Production code is unchanged. The campaign
remains stopped. No project scan or analyzer engine run was started.

`RelationAndQuery.lean` has 13 checked constructive claims:

- Literal payload inclusion preserves replies for any fixed per-leaf operator.
  Its native use requires identical complete premises and compatible headers.
- MUST/MAY handoff projection is not injective.
- Equal late concrete-point query keys do not imply equal raw STAR/EXACT transfer.
- The displayed point and ancestor-MAY C2 families differ literally.
- A positive Horn rule with a weaker premise covers the corresponding stronger
  premise logically. This does not prove a native ND deletion rule.

Only `propext` and `Quot.sound` occur in the axiom audit. The component does
not prove an arbitrary AP subsumption algorithm or whole-engine preservation.

`NativeOperatorReview.java` checks the real scalar application and C2/C5 APIs:

```text
B1: exact actual satisfies STAR, but not the corresponding MUST current premise.
B2: STAR output carries f; EXACT output returns the root.
    Their late concrete-point C2 entries still give equal initial families.
C1: ancestor MAY lacks the displayed exact concrete C2 initial.
    Both C5 entry-image checks accept that exact stored point.
```

These distinctions refute an unrestricted lifting of query equivalence to raw
transfer equivalence. They prove neither a project false negative nor that Z
is necessary for every possible C1 proof.

Native verification uses the dataflow JAR pinned by the existing classpath
snapshot. Its SHA-256 and the two relevant class hashes are in
`native-receipt.json`. No observer agent or application state is needed.
One metadata preflight rejected before compilation; that record is preserved.
The subsequent compilation and execution passed.

See `lean-receipt.json`, `lean-output.txt`, `native-receipt.json` and
`native-output.txt` for the actual results. The main review is
`docs/design/bidirectional-demand-edge-redundancy-patterns.md`; the separate
demand catalog retains the original examples and accepted certificates.
