The model separates fixed C5 entry checks from the unchanged native output body,
including arbitrary protection parts and normalization. It proves ordered paired
row results and diagnostic row-reference order remain equal. One C2 scope-answer
bundle supplies exact ordered labelled/unlabelled projections and preserves all
three observation families. A bounded owner-quantum memo preserves exact answers
and any finite adaptive query program without a hit-rate premise. Weight gates
can refuse storage without changing answers or work/completion state.
Capacity and per-entry bounds imply the selected total reference-count bounds.
Pattern-only member templates equal native normalization under the explicit
DATA kind guard. Empty port certificates allow only DATA-only observer replay
to be omitted; native Reach-to-Target is an explicit counterexample.

The finite CEGAR witnesses reject normalized-key/annotation shortcuts, crossed
entry/exit permissions, unary ND execution, wrong NORMAL FLOW STAR preimages,
incomplete cycle originals and ZERO/Target policy changes. Exact native fallbacks
cover run 2/static completion/carry/control/Reach. Full observation-result memo is
deferred. The checked model is not a proof of Kotlin AP/store/actor adapters or a
project speedup. No runtime, Gradle, analyzer, JFR or MAT work is included.
