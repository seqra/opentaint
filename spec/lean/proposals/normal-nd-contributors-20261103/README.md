Date: 3 November 2026. Status: **selected correction; finite model checked**.

The checker uses Lean 4.33.1 and one worker. It compiles the executable
model, audits every explicit public definition and theorem, and rejects
unproved declarations, choice, and native-evaluation proofs. The
[receipt](checks.json) gives the exact inputs and the
[portable axiom audit](audit.txt) gives the declaration-level result.
The baseline pins name immutable Git blobs, not the changing implementation.
This package does not change the earlier loop-block proof receipts.

`Contributors.lean` models an accepted condition image as a complete
conditional edge. Its original premise, scalar field geometry, mark, tail,
exclusions, protection, and layer are values. Premise atoms identify
immutable semantic initial facts; they are not mutable interner addresses.
NORMAL images are saved at the same owner, configuration, method context,
block/entry, operation, semantic stage, phase, rule, and leaf. FULL forward
mode is required. Backward and GROUP evidence cannot enter this cache.

The finite ordinary join enumerates complete bindings from an explicit
certificate catalog. Separate generic proofs establish that this enumeration
contains every available complete binding and contains only accepted,
same-site certificates. This is an executable finite reference, not an
assumed desired-output oracle. It uses explicit condition alternatives to
state the complete bindings; it does not authorize production DNF expansion
or replace the existing NNF evaluator.

The reuse algorithm seeds its pool without running actions. Only a current
same-site `Holds` activates the join. That activation can emit an already
complete saved binding. Its premise contains only its selected contributors;
an unrelated activating leaf adds no premise or layer. A nonmatching check
cannot activate it. Incomplete NORMAL leaves survive, completed-state dedup
resets each run, and a repeated certificate does not emit twice in that run.
Final complete bindings are independent of current arrival order. Callback
chronological order and batch-dependent diagnostics are not asserted equal.

The model proves every contributor premise survives. A mixed ZERO/nonzero
cube has no independent ZERO arm. NORMAL requires all selected contributors
to be NORMAL. It copies the full accepted fact payload. A current source
callback still needs the unchanged permission predicate. Saved certificates
do not become `Triggers.parts`, CFG packets, source hits, initials, demands,
or reports merely because a snapshot is loaded. Successful publication
extends the old snapshot; failure/cancellation leaves it unchanged.

The semantic-stage model identifies CALL_SINK outgoing addresses with one
BOUND condition point. Source and conjunctive phases stay distinct. This
normalization concerns condition ownership; it does not alter a real
request/resume address or the separate call-summary E6 join.

Finite controls cover the SESSION/DATA gap, old conditional P plus current
Q, NORMAL plus DEMAND, cached-complete activation by another accepted leaf,
nonmatching activation, caller premise rejection, metadata preservation,
rule/site isolation, and duplicate restoration. These prove the selected
local laws. They do not prove whole-driver convergence or project quality.

The runtime correspondence still needs native checks. In particular, the
model starts from a valid `MarkCheck.Holds` certificate and a supplied
condition topology; it does not prove AP matching, predicate compilation,
packed joins, source actions, the driver barrier, or callback scheduling.
Runtime Facts equality can omit protection metadata. The adapter must use
the existing annotation-aware AP merge/replay, rather than drop an equal
semantic fact with a protection upgrade. Scalar full-value equality here
is not a proof of that packed implementation. Source permission, complete
ND execution, Target handling, existing run-1 origin splitting, and current
observation packets must stay in the ordinary callbacks.

The correction changes evidence lifetime and point ownership. It does not
change ZERO admission, C2/C5, field transfer, source authority, or Target
composition. It is separate from the unselected ZERO-control draft.
The last measured pre-correction OWASP attempt completed and accepted run-5
with 18 missing identities. The latest native trust-boundary counterexample
completed run-3 without its finding. Neither is validation of this correction.
