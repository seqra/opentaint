# E07 finite closure and schedules

The finite fixture has stable methods, full context keys, explicit graphs and
immutable forms in both directions. Raw demand, record and seed inputs stay
separate from the production indexes. The direct closure scans these lists.
It uses per-path forms and exact sets, with no trie, tree, subsumption or
asynchronous delivery. Native pending returns retain E through RETURNED
actions and bindings. Only the finalized call-plan exit enters the caller.

The schedule uses actual method actors, handlers, summary storage and
subscriptions. One event pool selects events, partial Work, deferred replay
and notification. Same-unit calls use the actual direct handler. Other calls
use events. Work retains one reservation through partial execution. Duplicate
delivery is selectable. Quiescence snapshots include unchanged processed
facts, initials, raw summaries, actual stored publications, selected demand,
links, requests, backward source hits and sink witnesses. A callback failure
does not freeze an unfinished actor. Every mismatch carries its program and
decoded event trace.

Stored edge comparison uses full unions of bounded locations and marks. It
keeps the method, statement, premise, layer, base, kind and semantic component.
FLOW compares correlated input/output locations. Normal exact and must facts
remain separate. Tests reject a fold that changes E and mark exclusions at
the same time. Raw observations retain all annotations. Added links and sink
facts also compare their whole conclusion union, with their full caller and
ordered literal support headers. This does not change actual link or witness
storage.

## Fixed controls

The fixed programs cover exact getter paths, restricted must exclusions and
reduced publications, full-context sinks and conjunctions, static position
and mark request chains, same-call E6, strong writes and selected cleaning,
positive field cuts, native exact identity and memory effects, native pending
must returns with sibling aliases, backward zero and end-fact triggers, and
all three permitted backward record views. The 17-context fan-out tests
verify registration before publication, admitted siblings and excluded
fields, for may and must consumers in both unit layouts.

The split E6 control pins an early literal subscription before the ND
publication delivery, and a second literal subscription after that delivery.
Replay completes the same consumer call. It tests normal and mixed layers.
The first version agreed on closure but failed the strict arrival order:
the zero path traversed the delay before either nonzero literal. The final
fixture stops zero at node 2 and uses a separate nonzero signal for the
delayed conditional literal. It retains the full order assertions.

## Seeded schedules

Six program families each run 32 unique seeds in two unit layouts. Seeds 0
and 1 each repeat with a fresh scheduler on the same fixture. All 408
executions pass (`/tmp/bidi-e07-seeded-6.log`). The 24 repetitions have
identical complete raw observations and decoded traces. Quanta alternate
between one and two; a seed bit enables duplicate delivery. The families are
getter in run 1 and restricted mode, static requests, cleaner/strong write,
exact and pending native returns, backward record views, and split ND with
normal and mixed layers.

Support confirmation and constructed hand-offs depend on D01 and D02.
E07 retains and compares their raw inputs. V4 tests their completed outputs.
