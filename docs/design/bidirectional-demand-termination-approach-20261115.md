## 2. Domain: NE is part of the approach

```text
DATA = (base, path, tail, mark, E, mx, layer, H)

$ = EXACT     * = correlated STAR
M = MAY       NE = non-empty MAY       MUST = uniform taint
F = FLOW      N = NORMAL               D = DEMAND
E = real field exclusions after path
mx = full marks excluded from FLOW
H = existing literal protection membership
```

For the field alphabet Sigma:

```text
path.$ = path.{epsilon}
path.M = path.Sigma*
path.NE = path.Sigma+
M = $ union NE;         $ intersect NE = empty
```

NE is uncertainty about **some nonempty suffix**. It does not select its
first field and does not prove uniform taint. A MAY or NE output can choose
its suffix independently of its premise. STAR instead transports the same
symbolic suffix through a correlated relation. MUST proves the mark at its
represented locations; it is not another uncertain suffix token.

Loss-created MAY and NE are D with Empty E. Preserve their mark, mx and H.
C2 treats a submitted STAR as nonempty for query selection; ordinary STAR
matching and suffix correlation are not redefined by that admission choice.

| Role | Legal tails |
|---|---|
| Raw owned DATA initial/member | EXACT, STAR; forward MUST in its existing lane |
| DATA result or submitted actual | EXACT, STAR, MAY, NE; forward MUST |
| Frozen entry selector Dc | STAR, MAY, NE; concrete EXACT; FLOW mx is Empty |
| Ordinary paired exit Dp | EXACT, STAR; existing forward-origin MUST and virtual MAY cases; FLOW mx is Empty |

MAY and NE are never owned premise members, including ND and Target premises.
Ordinary Dp therefore cannot be NE. EXACT/FLOW is a raw initial, not a frozen
FLOW demand entry. Backward MUST remains invalid. ZERO and Targets have no
DATA tail. Static anchors stay indivisible; class anchors count as zero fields,
named fields and array elements count as fields.

NE is included in equality, hashing, freshness, delivery and handoff.
Keep H=false and H=true as distinct memberships. Do not OR-collapse them.
Pass rules carry protection and never create it.

### Real truncation

```text
cut(c,k):
    if FL(c.path) <= k: return c
    retain its prefix through k counted fields, including the static anchor
    replace the removed suffix AND old tail by NE
    set layer=D and E=empty
    preserve mark, mx and H
```

A real field was removed, so even an old exact point has a nonempty suffix
at the retained head. Apply this at every existing cut site, including
run-1, instruction/call/alias results and block/summary boundaries. Do not
add extra cuts or weaken an uncut MAY to NE.
An existing deliberately broad protocol answer, such as a run-1 static-pool
MAY supply, remains MAY. Its canonical key is not proof of a real field cut.

```text
x.f.g.h.$/T,N --cut to FL 1--> x.f.NE/T,D
x.f.M/T,D   --no real cut----> x.f.M/T,D
```

### Transfers and spatial checks

```text
y=x.f;  x.NE   -> y.M,D       // unknown nonempty suffix may be exhausted
y=x.f;  x.f.NE -> y.NE,D      // only a known prefix is removed
y=x.f;  x.$    -> no y
x.f=y;  y.M   -> x.f.M,D      // preserve the known written field
x.f=y;  y.NE  -> x.f.NE,D
```

If the last two results are then cut before f, both become x.NE/D. Do not
turn uncut x.f.M into x.f.NE: y's root may have been written at x.f.
A same-head exact check cannot match NE. A strict descendant may match it.
Partial cleaner survivors retain their selected semantics and protection;
no new STAR-cleaner-to-NE conversion is introduced.

### Layers, companions and NE filtering

- FLOW hypotheses start N. Concrete STAR starts D.
- Concrete EXACT/MUST starts N only with actual N support. A point guessed

- An admitted concrete STAR also has its same-geometry STAR/FLOW companion,

- If MAY admits a strictly deeper actual, retain the conditional EXACT/FLOW

command **at NE's original head**. Keep legal exact descendants, STAR,

### Retain real E at an unchanged head

demand family**, retain the actual's real field holes on any existing

```text

### Only FL(Dc)+1 exception: a NORMAL MUST actual with a deeper real hole

```

Start with the complete C2 family, including the same-head E rule above.
Map its existing eligible commands; do not add one:

```text

        q.path = actual.path
        q.E = actual.E
```

Only two existing command forms can stretch past Dc+1: the concrete STAR/T
start on DEMAND and its same-geometry STAR/FLOW conditional NORMAL companion.

EXACT prefix probe is unchanged. Existing same-head MUST admission is not
split. There is no extension for STAR actuals, DEMAND actuals, EXACT/MAY/NE
actuals, empty E, FLOW-only demands, GROUP, backward runs, precise demands,
failed admission or an already excluded old command.

The new initial may retain several already known fields, but never a field
beyond the actual or the global limit. No fixed Dc+2 cap is implied. The
proof constructs an old admitted member and the full exception certificate
for **every** emitted initial exceeding Dc+1. This is the exhaustive list.

old: p.f.*/T {},D      companion p.f.*/FLOW {},N

exactly the actual's geometric points without gaining uniform-mark support.

The correctness target is eventual refined observations under an uncapped
schedule, with the analyzer's separately selected semantics. These rules
prove natural stopping of the supplied references. They are not a global
proof that every launched forward run in every program advances precision.

The new tail is a constant-size header. Base MAY splitting has at most two
primary starts plus its existing companions; an observed-field plan has
at most `2+2k` starts and never recursively expands them in one preparation.
Use a structural equivalent of the raw C2 image in production, not the
finite-domain enumerator used by reference proofs. Existing indexes should
select relevant complete C5 rows before intersection.

Uniform providers are keyed by complete P, lane, H and output base. A scalar
scan over k providers costs O(k*L) for path limit L; an appropriate qualified
prefix trie can find an eligible ancestor in O(L). Routing reuses native
matching's first-unknown-field descriptor and the prepared mask. These are
bounded local lookups, not cross-call suffix or origin products. The latest
filters add no raw queries; their fixed-plan output is a subset of native
contributions. No universal bound on later whole-run membership is claimed.
Definite reply support uses one temporary hash set of eligible NORMAL
keys in the existing reply batch and one filter pass: O(n) expected key
lookups for n leaves, or O(n*L) including scalar path hashing. It adds no
propagated edge, subscription, field query, persistent input cache or suffix
product. It does not retain full truncation evidence.
